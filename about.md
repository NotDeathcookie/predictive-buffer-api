# Predictive Buffer API

Shared engine for Geometry Dash input-buffer mods. **This mod does nothing by itself**; install it only because
another mod asks for it.

Developers: see the repository docs for how to build a buffer mod on top of it.

Credit: the prediction approach and reference behavior come from **Predictive Buffer by lilWC**. The richer
delay search, learn-from-attempts memory and orb-aim logic in `pbuf.trajectory.advanced` come from
**GD-Input-Buffer by AlQuerez**, used with permission - see `docs/GD_INPUT_BUFFER_INTEGRATION.md`.
